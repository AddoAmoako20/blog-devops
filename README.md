# Blog DevOps

This is a blog website I'm building while learning DevOps and backend development.

I'm using this project to practice things like Docker, PostgreSQL, Git, GitHub, CI/CD and AWS instead of only learning them from tutorials.

## What I'm using

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- PostgreSQL
- Docker
- Docker Compose
- Git
- GitHub
- GitHub Actions
- AWS
